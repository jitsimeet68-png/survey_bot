# Базовая документация чат-бота для опросов

## Назначение
Проект предоставляет чат-бота, который проводит опросы, собирает ответы и передаёт их в серверную часть для анализа.

## Основные компоненты
- `backend/` — обработка сообщений, сценарии опросов, запись результатов в хранилище.
- `proxy/` — конфигурации сетевых сервисов, проксирование трафика к backend.
- `docker-compose.yml` — описывает набор контейнеров проекта и их зависимости.
- `Makefile` — часто используемые команды для локальной разработки и деплоя.

## Быстрый старт
1. Установите Docker и Docker Compose.
2. Скопируйте переменные окружения из `backend/.env.example` или настройте свои.
3. Запустите `docker-compose up --build` из корня репозитория.
4. Убедитесь, что бот подключён к выбранной платформе (например, Telegram) и отвечает на сообщения.

## Разработка
- Изменяйте код в `backend/` и перезапускайте соответствующие контейнеры.
- Используйте `make lint` и `make test` (если настроены) перед коммитом.
- Для отладки сценариев опросов обновляйте конфигурацию в backend и перезапускайте сервис.
