# Документация по проекту чат-бота

## Общее описание
Этот проект реализует чат-бота для проведения опросов. Он собирает ответы пользователей, обрабатывает их и сохраняет результаты для дальнейшего анализа.

## Основные возможности
- Отправка пользователям вопросов опроса в интерактивном режиме.
- Сбор и валидация ответов.
- Хранение результатов в базе данных.
- Настраиваемые сценарии опросов.

## Структура проекта
- `backend/` — серверная часть бота, логика обработки сообщений и взаимодействие с базой данных.
- `proxy/` — конфигурации и службы, обеспечивающие сетевое взаимодействие бота.
- `docker-compose.yml` — конфигурация запуска сервисов в контейнерах.
- `Makefile` — вспомогательные команды для разработки и деплоя.

## Развертывание
1. Убедитесь, что установлены Docker и Docker Compose.
2. Выполните команду `docker-compose up --build` для запуска всех сервисов.
3. После запуска убедитесь, что бота можно подключить к нужной платформе (например, Telegram).
